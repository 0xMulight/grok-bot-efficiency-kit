Quick Start

先跑通，再自动化。

● ● ●   Python 3.10+ · 零第三方依赖 
# 先验证环境
python -m grok_kit doctor

# 估算 Routine 调用次数
python -m grok_kit audit examples/routines.example.json

# 查询一个 BSC CA
python -m grok_kit ca 0x55d398326f99059ff775485246999027b3197955
① 下载仓库、解压
Windows 10/11 也可以直接双击「启动工具.bat」。
② 先试离线审计与 CA 查询
不需要钱包，不需要任何签名或授权。
③ 监控 BSC 时配置 RPC
必须选支持日志查询的 HTTPS 节点；不少公共 RPC 不支持。
④ 最后才连接Webhook
只从你自己 Bot 的 Routine 复制URL和密钥。发送事件会消耗用量。

Safety First

该做的写清楚，不该做的绝不碰。

🛡 无钱包权限

不读取私钥、助记词、不签名、不授权，也不自动买卖或 Mint。

🔒 密钥留在你电脑

RPC 连接信息与 Bot Webhook Bearer 密钥只存在未提交的本地配置中。

🎯 只承诺真实覆盖

新池监控不等于Agent ID项目识别，不覆盖所有DEX或Mint事件。

🧾 来源与未知值

查询失败就标 UNKNOWN；Routine报告是次数估算，不是官方Token账单。

本项目与X、xAI、Binance、BNB Chain、PancakeSwap无官方关系。所有功能需自行配置与验证；不构成投资建议。安全细则 ↗
